# E-VISIOCAM - Backend

API Node.js + Express + Socket.io + SQLite

## Endpoints
- `/api/health` - Health check
- `/api/auth/*` - Login / Register
- `/api/users/*` - Profil utilisateur
- `/api/admin/*` - Admin
- `/api/mod/*` - Modération
- `/api/model/*` - Dashboard modèle
- `/api/credits/*` - Crédits et paiement
